馬洛 · Marlowe

最終 BOSS · Colin Marlowe · 任務 Hunt Marlowe · Clive Barker's Hellraiser: Revival（養鬼吃人：復甦）· 最高難度 Hellraiser

只打背體，鎖鏈開殼——霰彈貼臉，慳彈先係硬核
最終 BOSS Hellraiser: Revival 難度 Hellraiser 無 autosave Save Token 成就 Go to Hell!

身份

  • 猩紅教會（Scarlet Church）領袖
  • 全名 Colin Marlowe
  • 異變後最終戰體

核心循環

  • 背上三具發光人體（橙光弱點）
  • Hellchains 撕開外殼
  • 霰彈打本體 → 半血換場再做

終結

  • 殼開、馬洛掉出
  • 機關盒（Genesis Configuration）互動放逐
  • 取得 Marlowe's Heart 交 Sunny

粵語 Tip

  • 進教堂／開打前手動存檔
  • Hellraiser 檔無 autosave；死＝倒退上次手動存
  • 唔好浪費子彈打外殼
PREP · ZORA SHOP

戰前商店

最終戰前最後一間 Zora 商店——最後一次買／造機會。Hard／Hellraiser：進場前務必手動存檔。

優先 項目 原因
1 Shotgun ＋ Dragon Breath（龍息彈） 暴露窗主輸出；火屬性對 BOSS 通用
2 Assault Rifle（AK）／Revolver／SMG 彈 快速清背上三具人體弱點
3 Hellchains 充能 強制開殼／末段定身
4 Genesis Configuration（念力／拉物） 點燃火盆、拉尖刺牆／陷阱
賣 全部近戰 多數指南一致：此戰只用槍＋機關盒換子彈

Hellraiser：彈藥極缺。場內木箱有彈但邊打邊撿危險——戰前商店囤夠先入。

PHASE 2 · ARENA

P2環境

半血換場後優先用環境傷害慳彈。基礎循環仍係背體→鎖鏈→霰彈；以下係進階補充——每項都有短片喺 #moves。

尖刺石牆

  • 機關盒拉起尖刺牆
  • 誘衝撞牆＝免費傷
  • 短片：#move-spike

旋轉柱／陷阱

  • 念力拖到場中或砸向佢
  • 慳霰彈窗口
  • 短片：#move-traps

吊掛方塊

  • 射圓環鏈節（射塊身唔跌）
  • 末段可用 Hellchains 定身再砸
  • 短片：#move-blocks

火盆（P1 可用）

  • Genesis 念力點燃
  • 輔助開局／補傷

Ammo 原則：只打背體＋暴露窗；P2 優先環境傷，彈留給開殼後貼臉。

HELLRAISER DIFFICULTY

Hellraiser注意

四檔最高：Easy → Normal → Hard → Hellraiser。只能開新檔時選，不可中途升上去。

  • 無 autosave → 進教堂／開打前手動存；Save Token 全關有限（各源約 11）
  • 死＝倒退上次手動存，其後拾取全失 → 唔好幻想「打到半血先存」
  • 彈藥極缺 → 商店賣近戰換彈；場內箱邊打邊撿危險
  • 被擊倒後抓技 → 即 mash 掙脫；藥同彈都緊
  • 以為比 Sister of Mercy／Charlotte 難 → 圖文多數評最終戰較易，但一次失敗代價大
  • 亂開修改器／無限彈 → 呢頁唔教；硬核就慳彈同存檔紀律
