源義經 · Minamoto no Yoshitsune

最終 BOSS · 任務《劍之道》· 蓮台野衝突／遮那王城天守 · 三血條連打 · PowerPyx 約 8.5/10

三階段連打無中途存——抓取必閃，覺醒留畀三階
最終 BOSS 蓮台野 劍之道 遮那王城天守 獎盃：真心感謝 Truly, Thank You

結構

  • 三階段／三血條連打
  • 無中途存檔
  • 只有鬼武者覺醒先打得到三階血量

一／二階主軸

  • 彈反（化勁）削耐力
  • 遠距光劍／能量多閃避
  • 發光手抓取必閃（大吸魂＋強化對方太刀）

三階主軸

  • 普攻唔掉血／只削耐力
  • 搶吸魂 → 變身 → 一閃 → Onslaught
  • 預期約 2–4 次覺醒

練習

  • 鍛鍊之間 Boss Rematch
  • 先 Action 再開 Carnage／鬼殺
PREP · LOADOUT

戰前裝備

道具盡量留到二階段後半～三階段。御守優先覺醒／鬼力；技能要有第三御守位同 Onslaught 強化。

御守

  • 覺醒御守
  • 鬼力御守（Restless Spirits／不穏な魂副線）
  • 劍士之力
  • 第三槽（Charm Capacity 2）

消耗

  • 內觀護符 ×2
  • 興奮劑 ×2
  • 高級防禦／力量護符 ×2
  • 重型恢復藥 ×2
  • 日曬乾穗 ×1
  • 反魂鏡（Mirror of Revival）

技能／鬼武具

  • Onimusha Onslaught: Power
  • 完全鬼之覺醒類
  • 地鳴雙錘等利削耐力／吸魂窗 i-frame
  • 二周目可推魔笛【火鳥】炎上

粵語 Tip

  • 第一次鬼殺：一二階唔開覺醒，滿槽入 P3
  • 肩敲＝彈反 cue，貫穿三階
  • P2 處決優先紫魂喂覺醒

PHASES

三階段短結

一階 · 太刀對決

  • 彈反削耐力；紫氣完美格／化勁
  • 肩敲 → 高速突刺＝彈反 cue
  • 白光／粉紅遠斬：近擋遠閃
  • 雙足飛踢可一閃打倒
  • 抓取必閃——被抓大吸魂並強化對方太刀

二階 · 全身鎧甲

  • 開場空中猛砸＋地裂——一恢復控制即往遠處衝刺
  • 鎧甲令普攻幾乎削唔到耐力；靠彈反＋破甲
  • 箭雨可彈；遠距瞬移抓
  • 處決選紫魂（喂鬼力／覺醒），唔好貪紅魂直傷

三階 · 覺醒限定

  • 非覺醒無法傷害血量（普攻只削耐力）
  • 攢紫魂 → L3+R3 變身 → 狂打一閃
  • 吸魂（Soul Drain）時用籠手搶魂，否則全屏斬≈即死
  • Onslaught／奧義：槽將盡或打斷吸魂後大斬

PHASE 3 LOOP

三階段循環

非覺醒狀態無法傷害血量。目標：穩定重複「搶吸魂 → 變身 → 一閃 → 槽尾／吸魂窗 Onslaught」，約 2–4 次覺醒收工。

01搶吸魂 → 02L3+R3 變身 → 03狂打一閃 → 04槽尾／吸魂窗 Onslaught

粵語操作清單

  1. 用一閃＋氣焰路線攢紫魂（P2 處決已優先餵過）。
  2. 槽夠即 L3+R3 開鬼武者覺醒——只有呢段先打到血。
  3. 覺醒內主打一閃輸出；唔好浪費時間普攻磨耐力。
  4. 見到 Soul Drain／全場真空：用籠手搶魂；已覺醒可用 Onslaught（R1） 打斷吸魂後大斬。
  5. 一般輸出：奧義／Onslaught 留到覺醒槽將盡（傷害更高）；見到吸魂就優先打斷。
  6. 槽盡退出覺醒 → 再攢紫魂 → 重複，直到擊殺。

詳細英解見 Tenkiei @ 551s；簡化路線 tateyou 1SCpQfvBT2k @ 329s。

DISPUTED

衝突／未定資訊

多源有出入；頁內「建議」跟核實稿。補丁會改手感，以遊戲內同 PowerPyx／主 walkthrough 為準。

議題 說法 A 說法 B 建議
一二階開唔開覺醒 allthings.how／多數：留滿入三階 TheGamer：P1 可開覺醒＋一閃削半血；Maxroll：魂易被偷，未熟練當 use-it-or-lose-it 鬼殺／第一次打：優先留滿或接近滿入 P3；熟練可 P1–2 消耗再 farm
吸魂後全屏斬 PowerPyx／GamerSky／Ludens：中招≈結束 Maxroll：中一兩次唔等於全滅 仍當最高優先躲避；有 i-frame／覺醒 Onslaught 就打斷
Onslaught 時機 槽將盡先放（傷害更高） 專用打斷 Soul Drain 大斬 兩者都啱：一般收尾放槽尾；見到吸魂＋已覺醒就優先打斷
P2 普攻削耐力 Wiki／Ludens：鎧甲令普攻幾乎無效 TheGamer：仍靠彈反／處決削 以彈反為主，唔好硬砍架勢
巨大白光／粉紅遠斬 近彈反、遠閃避 TheGamer：遠距建議閃避攢 Reflex 跟距離：遠閃、近擋／彈
P1 失敗抓取 Maxroll：即時強化太刀，令 P2 三連不可閃更難 其他源多只寫吸魂強化 抓取＝最高優先；P1 盡量零抓
MISTAKES

常見錯

  • 一二階狂開覺醒 → 第一次／鬼殺請留滿入三階
  • 被發光手抓仲當普通斬 → 抓取必閃；中招強化對方太刀
  • P2 開場原地硬擋地裂 → 一恢復控制即遠跑
  • P2 處決貪紅魂直傷 → 優先紫魂喂覺醒
  • 三階未覺醒硬砍血條 → 非覺醒無法傷害；先攢紫魂變身
  • 吸魂時企定唔搶魂 → 籠手搶魂；否則全屏斬≈結束
  • Onslaught 一覺醒就放光 → 一般留槽尾；吸魂窗先打斷
  • P2 硬普攻磨鎧甲耐力 → 彈反為主
