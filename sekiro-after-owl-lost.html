After Great Shinobi Owl · Kuro → Wedding Cave → Fountainhead Palace → Divine Dragon

城頂大忍貓頭鷹 ≠ 平田義父貓頭鷹。而家唔使打義父——下一站係乘轎石洞入源之宮。

NOW

你而家身處邊度？

對齊定位，唔好喺屋頂發呆又唔好飛去平田。

  • 鬼佛大概喺 天守閣・九郎之間（Upper Tower - Kuro's Room），或者屋頂打完剛落嚟。
  • 剛拎到 常櫻香木（Aromatic Branch）——大忍貓頭鷹掉落，斷龍胤四材之一。
  • 主線下一站唔係再爬城、亦唔係毒沼／白蛇神社。
同九郎／英麻講完 → 點源之香 → 傳去「乘轎石洞」祈禱 → 源之宮 →（之後）神龍。
IMMEDIATE

打完之後即刻做（必做）

落九郎房講到盡，再搞薰香——呢步唔齊，神轎冇「祈禱」。

1.1 落返九郎房

  1. 由天守閣屋頂沿梯落，入 九郎之間。
  2. 同 九郎、英麻 對話，講到對話重複為止（要多講幾次）。
  3. 九郎會認你已集齊斷龍胤材料，並講到入源之宮嘅事。
  4. 跟住搞 薰香／源之香：同英麻講、再同九郎互動香爐，用不死斬取血等（跟畫面提示即可）。

記得拎／確認

項目來源備註
戰鬥記憶：大忍貓頭鷹剛打倒可去鬼佛提升攻擊力
常櫻香木大忍貓頭鷹斷龍胤四材之一
芳馨水蓮獅猿（崩落谷・戲水處洞穴）見 補線
棲宿之石蘆之村幻影破戒僧後・乘轎石洞見 補線
不死斬仙峰寺・屏風猿後・變若卿子見 補線

若對話卡住、香爐撳唔到：通常係 四材未齊，先去 自檢／補線。

1.2（可選）英麻相關

打完大忍貓頭鷹後，休息／偷聽九郎幾次，英麻有機會上樓梯口。跟住佢對話會開結局相關選項嘅前置——而家可以做，亦可以稍後先做；唔影響你入源之宮。本頁唔展開結局細節。

PATH

主線：點入源之宮／神龍

一條線跟住行：九郎點香 → 乘轎石洞 → 源之宮 → 神域。

1九郎之間 → 2乘轎石洞 → 3源之宮 → 4朱之橋 → 5神域・神龍
天守閣・九郎之間 ↓（講完、點完香） 傳送到 → 葦名之底・乘轎石洞（Wedding Cave Door） ↓（入洞 → 入神轎 → 祈禱） 源之宮（Fountainhead Palace）第一鬼佛 ↓（過橋打「真・破戒僧」） 朱之橋（Vermilion Bridge） ↓（宮內推進） 水生御屋敷 → 賞花舞台 → 大櫻 → 宮之境內 … ↓ 神域（Sanctuary）→ 祈禱 → 神龍
A · 點完香之後
  1. 喺 天守閣・九郎之間 開鬼佛傳送選單。
  2. 揀 葦名之底（Ashina Depths） → 乘轎石洞（Wedding Cave Door）。
日文／部分攻略叫「輿入れの岩戸」。唔係毒沼鬼佛、唔係隱村、唔係水車。
B · 入神轎
  1. 由乘轎石洞鬼佛入去個洞（你之前拎 棲宿之石 嗰個洞）。
  2. 洞入面有座細細嘅 神轎／轎亭，入去。
  3. 出現 「祈禱」 → 確認。
  4. 過場：巨型注連繩會送你上 源之宮。
C · 源之宮開頭
  1. 沿草繩行，開第一個鬼佛 源之宮。
  2. 向前過橋 → 打 真・破戒僧（三管血；蘆之村嗰隻係幻影，呢隻係實體）。
  3. 打完開 朱之橋，之後一路推到 神域，喺祠祈禱入神龍戰。
神龍戰前建議：存檔、補血藥／糖、確認想做嘅支線／結局前置已做完（打完神龍後世界會推進）。本頁唔寫結局分支。
LOST

常見迷路

  • 打完貓頭鷹企喺屋頂發呆 → 即刻落梯返 九郎之間，同九郎／英麻講到盡。
  • 以為下一站係平田「義父貓頭鷹」 → 嗰隻係另一場（義父守護鈴／平田回顧）。主線而家係 乘轎石洞 → 源之宮。
  • 鬼佛搵唔到「乘轎石洞」 → 分類喺 葦名之底。若未開過：要由蘆之村打完幻影破戒僧再入婚洞拎棲宿之石（見 補線）。
  • 入咗洞但唔知做咩 → 唔好淨係企喺以前擺石頭嗰度；要入 神轎入面撳祈禱。冇「祈禱」＝多數未點香／四材未齊／未講完九郎。
  • 走錯毒沼／隱村／白蛇神社 → 獅猿→白蛇干柿→毒沼白萩係支線／強化，唔係入源之宮嘅門。入宮門係 蘆之村側・乘轎石洞。
  • 入咗源之宮又覺得「卡住」 → 正常：第一關卡係橋上 真・破戒僧。打完先有朱之橋，之後先係大地圖同神域。
MATERIALS

若未清線：點樣補

入源之宮硬條件＝斷龍胤四材齊 + 對九郎忠誠（你已打大忍貓頭鷹＝已選忠誠）+ 點香 + 乘轎祈禱。

4.1 芳馨水蓮（崩落谷・獅猿）

  • 打倒 獅猿 後，入戲水處洞穴拎 芳馨水蓮。
  • 你若已行過獅猿線，多數已有。背包冇 → 返 獅猿戲水處 附近洞穴撿。

4.2 棲宿之石（葦名之底・蘆之村）

若未開乘轎石洞／冇棲宿之石，補呢條：

  1. 入 葦名之底 → 過 隱村（霧之林）（要用花香球／引路蝴蝶；打頭目可選）。
  2. 到 蘆之村（Mibu Village）。
  3. 村內水道／水車方向推進，打 幻影破戒僧。
  4. 打完入後方洞 → 鬼佛 乘轎石洞 → 拎 棲宿之石。
  5. （之後先返城觸發內府／貓頭鷹入侵；你而家已打完貓頭鷹，只係補石再返九郎點香。）

4.3 毒沼／白萩

  • 毒沼鬼佛、頭目白萩等＝探索／念珠／道具，唔擋入源之宮。
  • 想清就清；急住推主線可之後返。→ 毒沼專頁

4.4 不死斬

  • 仙峰寺 → 屏風猿 → 內殿見變若卿子拎 不死斬。
  • 冇不死斬＝無法完成取血／點香流程。

AFTER

源之宮之後（極簡）

  1. 源之宮 → 橋 → 真・破戒僧 → 朱之橋
  2. 宮內推：水生御屋敷 → 賞花舞台 → 大櫻 →（可選探索湖底／餵鯉）→ 宮之境內
  3. 石階上到 神域 → 對巫女／祠 祈禱 → 神龍
  4. 打完神龍會返城，世界進入下一階段（內府大舉來襲）。之後有結局相關選項——本頁唔展開。
一句總結：落九郎房講完 → 確認四材 → 點香 → 傳乘轎石洞 → 入神轎祈禱 → 源之宮打真破戒僧 → 推到神域打神龍。 唔好去平田搵義父貓頭鷹，亦唔好喺毒沼等入口。
