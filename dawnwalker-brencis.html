布倫西斯 · Brencis

最終 BOSS · Vale Sangora 親王（Knyaz）→ 怪誕昇華者（Grotesque Ascendant）· 任務《與魔鬼的交易》· 30 遊戲日

盾標格、骷髏閃——藥留畀二階 solo
最終 BOSS The Blood of Dawnwalker P1 Greifberg P2 Anachora · Solo 與魔鬼的交易 進戰前手動存檔

兩階段

  • P1 Knyaz＠Greifberg Castle（亦見 Griefberg）
  • Cutscene 傳送 → P2 Grotesque Ascendant＠Anachora
  • 多數源：兩階段之間無檢查點

心法

  • 盾標 → 格擋／完美格／招架
  • 骷髏標 → 必須閃／Shadowstep
  • 紅幽靈先清，先後再打 Boss

盟友

  • Lacra／Crake 只限 P1
  • P2 一定 solo
  • P1 唔好花光藥

粵語 Tip

  • 進《與魔鬼的交易》前手動存檔
  • 留意30 日救家人時限
  • 最終 BOSS 係 Brencis，唔係源義經
ROUTES

進入路線

標準線：打完三博雅爾（Ambrus → Bakir → Xanthe）→ 惡名拉滿 → 隔日觸發會談。對話決定單人／Lacra／Crake／跳過。

路線 條件 戰鬥／結局
Solo／Folk Hero 會談選「Enough. Time to end this.」／「夠了。是時候結束這一切了。」 單人打 Brencis（最難）；獎盃 The Folk Hero
Lacra／Patricide Lacra 任務鏈 → Midnight Reckoning P1 有 Lacra；獎盃 The Patricide
Crake／Knyazmaker Manumit／Crake 鏈 → Rise at Dawn／Fall Before Dusk P1 有 Crake；獎盃 The Knyazmaker
Turncoat 接受 Brencis 交易、出賣 hideout 跳過 BOSS 戰；獎盃 The Turncoat
Early castle 夜爬牆（Planeshift＋Shadowstep）或側門鑰匙 提前結局序列；極難
Prologue win 序章 Bad Blood 打贏 Knyaz 即入 Ascendant；可提前完結（極難）

無 NG+；多結局靠讀檔。進終局前一定要手動存。

PREP

戰前清單

無可靠官方弱點表／HP／等級門檻。準備靠路線完成度同消耗品。

必做

  • 手動存檔（結局分支前）
  • 完成想要嘅盟友線再進會談
  • 留意30 日時限

消耗品

  • 血藥／Blood Vial 盡量帶齊
  • Solo 線再多帶
  • P1 慳藥畀 P2

技能工具（社群常見）

  • Swordmastery Charge（拉近＋硬直）
  • Voracious Bite 續航
  • Shadowstep／Planeshift 脫困

唔好假設

  • 元素弱點表
  • 固定等級門檻
  • 盟友減 Boss 具體 %

MISTAKES

常見錯

  • 骷髏標硬格／盾骷髏搞反 → 盾格、骷髏閃
  • 忽略紅幽靈被圍殺 → 先清 add 再打 Boss
  • 以為清空第一條血＝通關 → 仲有 Ascendant
  • P2 用 P1 遠距站樁 → 觸手射程遠，要移動閃
  • Soul Drain snare 冇閃 → 先閃第一下定身
  • P1 花光藥 → P2 一定 solo，藥要留
  • 未手動存檔就進結局叉 → 進會談前存
  • 超 30 日仲以為準時救家人 → 時限影響獎盃／結局
  • 中文站錯配源義經 → 最終 BOSS 係布倫西斯
